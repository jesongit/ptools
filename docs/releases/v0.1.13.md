# ptools v0.1.13

- 截图与贴图工具栏改为双排短布局，保留全部 22 个功能入口和原有分组菜单。默认 100% 缩放下宽度 364 px，框选/移动时高度 76 px，标注选项展开时 104 px；小工作区仍会适配布局。
- 颜色与粗细只在标注工具需要时显示；框选/移动和取色隐藏该行。马赛克色块只在画笔组出现。
- 粗细由三个预设按钮改为可拖动滑条，基础值 1–32，支持拖出控件边界后继续调整并钳制到端点。数值按工具显示实际线宽、荧光笔宽度、马赛克范围或文字/序号字号，只影响后续标注。
- 移除底部固定文字提示。鼠标停留约 350 毫秒后在指针附近显示悬浮提示，显示工具、快捷键或不可用原因，靠近屏幕边缘自动调整位置；拖动、离开、切换工具、关闭窗口时收起。提示不抢焦点、不拦截鼠标，关闭贴图时一起回收。

92 项工作区测试、格式检查与 Clippy 通过；239 项实际原生截图/贴图回归通过，覆盖新增滑条与提示，以及既有分组菜单、标注、OCR 和图片导出。100% / 150% / 200% DPI 的原生绘制结果已检查。

随包应用插件 0.1.5、截图插件 0.1.9，配置和历史继续保留。
