# ptools v0.1.12

Ctrl+1 截图进一步改善高分辨率、多显示器下的鼠标跟随：缓存暗色遮罩，按变化区域绘制边框、尺寸和放大镜，避免每次鼠标移动重画整个桌面。普通截图使用不透明窗口，长截图仍按需启用透明边框。截图原位贴图、标注及其他快捷键继续保留。

实际可见的 5760×2160 双屏截图窗口，40 帧对比中，拖动消息到绘制完成的中位值由 100.0 ms 降为 0.77 ms，等待桌面合成后的中位值由 101.2 ms 降为 6.9 ms。测试使用原生鼠标消息、UpdateWindow、GDI 和 DWM 刷新，代表受控软件路径，不代表物理鼠标到显示器的端到端延迟。

87 项工作区自动化测试通过；逐像素对照覆盖局部刷新残影；233 项实际原生截图/贴图工具回归通过。长截图的 80 项绘制、透明边框和像素输出检查通过，后续真实键盘用例因前台焦点未取得而未完成。旧选择/编辑脚本的剪贴板哨兵检查受到外部输入法剪贴板监听干扰，未作为通过项。
