# ptools v0.1.14

- 截图与贴图共用并记住上次标注颜色、粗细，新建窗口和重启插件后继续沿用。选色立即保存，滑条松开或失去捕获后保存；已有标注保持原样。荧光笔不再强制重置为黄色，马赛克不覆盖记住的真实颜色。
- 文字框选合并到第一个框选按钮，默认显示文本框与 I 形文字光标；再次点击切换为普通鼠标箭头并关闭文字框选。返回框选保留开关状态。工具栏仍为双排短布局，合并后共 21 个入口。
- 仅在框选工具下选择文字，矩形、画笔等标注工具直接绘制；切换工具清除旧文字选区。贴图按空格进入编辑时默认选中第一个按钮。
- 修复连续点击或双击第一个工具栏按钮会误完成、复制并关闭截图的问题。V 与 Shift+C 按住时不再反复切换。
- 截图与贴图画布直接接收工具快捷键，避免中文输入法吞掉字母按键，并兼容 VK_PROCESSKEY。文字标注输入框继续使用输入法上下文，输入文字不会切换工具。

验证：95 项工作区测试、格式检查与 Clippy 通过；257 项实际原生界面回归通过，覆盖连续点击、文字与绘制分工、跨进程颜色/粗细记忆，以及中文输入布局下真实注入的 R/P/T 工具切换。文字编辑的输入法上下文与中文消息输入另有自动化测试。原生绘制证据覆盖 100% / 150% / 200% DPI；未穷尽所有第三方输入法和跨显示器 DPI 切换。

随包应用插件 0.1.6、截图插件 0.1.10，配置和图片历史继续保留。
