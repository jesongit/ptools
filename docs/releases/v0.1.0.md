# ptools v0.1.0

首个 Windows x64 版本：Rust 原生搜索框与按需运行的应用启动插件。

## 下载与使用

- 下载 `ptools-0.1.0-windows-x64.zip`，完整解压后双击 `ptools.exe`。
- 主程序已附带应用启动插件；`applications-0.1.0.ptplugin` 用于单独安装或重装该插件。
- `SHA256SUMS.txt` 提供两个分发文件的 SHA-256 校验值。

## 功能

- Alt+Space 唤起或隐藏；窗口在鼠标所在屏幕的可用区域居中，适配不同 DPI。
- 按应用名称、中文拼音或首字母搜索，支持最近使用与使用频率排序。
- 方向键或 Ctrl+J/K 上下选择；Alt+数字仅选中当前可见的对应项目，Enter 执行。
- Tab 打开内置菜单；Esc 返回或隐藏。托盘右键仅保留“关闭”，直接退出。
- 插件可单独安装、启停和卸载，支持配置插件与 EXE 插件；应用发现进程刷新完成后退出。
- 默认数据保存在用户目录；可使用便携模式。支持更换快捷键和可选的开机启动。
- 修复 Windows AppData 重定向导致的插件路径误判与刷新失败。

## 验证范围

在 Windows 11 x64 验证构建与应用发现；界面检查覆盖 100% / 175% 缩放及双显示器切换。路径校验、插件生命周期和启动链路有自动化检查；Alt+数字已验证为只选择，Enter 才执行。

Windows 10 为目标系统，尚未进行真机验收。首版插件采用本项目协议，不兼容 uTools 插件，也不内置 JS 或 WebView 运行时。详细验证记录见 `docs/verification.md`，插件开发说明见 `docs/plugin-development.md`。
