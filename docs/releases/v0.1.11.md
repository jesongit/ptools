# ptools v0.1.11

- 移除列表序号与 Alt+数字选择；新增启动器内 Ctrl+R 后台刷新应用索引，保留查询。
- 符合全部查询条件的结果优先按累计启动次数排序，次数相同时比较匹配程度、最近使用时间和标题。复用原有使用记录，空查询显示常用应用。
- 截图的控件探测改为后台执行，慢程序的控件响应不再阻塞鼠标消息；截图底图和绘制缓冲复用。
- 截图按钮贴图和 Ctrl+2 均保留原选区的物理坐标与尺寸，复制截图后再贴图也保留位置。其他来源的剪贴板内容继续居中贴出。
- 随包应用插件 0.1.3、截图插件 0.1.7；配置、历史与快捷键设置继续保留。

自动化覆盖查询过滤与频率排序、异步探测阻塞与过期结果、截图原点/阴影补偿、实际贴图窗口矩形、剪贴板位置格式，以及既有截图标注和发布更新回归。真实鼠标手感与日常实例完整更新验收另行记录，不以单元测试代替。

构建与检查：86 项工作区自动化测试、格式检查、Clippy 和完整包校验通过。4K 底图绘制基准由约 67 ms 降至约 3.6 ms（只衡量底图绘制）。
