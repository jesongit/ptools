# Windows 快开与启动插件边界

应用启动插件除发现应用外，还提供 58 个 Windows 管理工具、设置页面和常用文件夹入口（本机缺少的系统文件会被过滤）。按 `Alt + Space` 输入名称，选中后按 `Enter`；支持中文、拼音、首字母、英文和常见系统命令别名。停用应用启动插件会同时隐藏这些入口。

| 类别 | 常用入口 |
| --- | --- |
| 管理工具 | 设备管理器、任务管理器、磁盘管理、计算机管理、服务、事件查看器、注册表编辑器、资源监视器、系统信息、系统配置、组策略编辑器、任务计划程序、磁盘清理、高级安全 Windows 防火墙、远程桌面连接 |
| 经典控制面板 | 控制面板、高级系统设置、网络连接、声音控制面板、程序和功能、电源选项 |
| 系统设置 | Windows 设置、显示、声音、音量混合器、蓝牙、打印机、鼠标、网络、Wi-Fi、代理、VPN、电源、存储、通知、剪贴板、远程桌面 |
| 应用与其他设置 | 已安装应用、默认应用、启动应用、日期和时间、语言、个性化、任务栏、账户信息、Windows 更新、Windows 安全、恢复、系统关于 |
| 常用文件夹 | 此电脑、回收站、桌面、下载、文档、图片、启动文件夹 |
| 终端 | 命令提示符、Windows PowerShell |

示例：“设备管理器”、`shebeiguanliqi`、`sbglq`、`device manager` 和 `devmgmt.msc` 都指向同一入口；“系统工具”“系统设置”等分类关键词可用于浏览。文件夹使用 Windows Shell 已知目录，尊重用户移动或重定向后的路径。

系统工具只索引本机存在的文件。例如没有 `gpedit.msc` 的 Windows 家庭版不会显示组策略编辑器。部分设置页依 Windows 版本、硬件和组织策略提供，打开行为由 Windows 决定；Wi-Fi 设置需要无线适配器。入口只打开管理界面，不直接修改设置、清空回收站或关机。

系统入口和现有应用同名时保留系统入口及其别名，减少重复结果。入口 ID 在刷新间保持稳定，沿用使用频率排序和最近使用记录。索引完成后应用插件退出，系统快开不增加常驻进程。

## uTools 常见功能的归属

uTools 官方提供本地搜索、网页快开、OCR、剪贴板、翻译等插件，系统工具市场也有应用、文件夹、网址和插件的聚合启动工具。下面是 ptools 的归属原则，独立功能不因共用搜索入口而并入启动插件。

| 功能 | 归属和现状 |
| --- | --- |
| 应用、Windows 系统工具、设置页、常用目录 | 应用启动插件；已支持 |
| 自定义文件、文件夹、网址 | 已有配置插件的绝对路径和 HTTP/HTTPS 入口；未来可增加图形编辑界面 |
| 截图、贴图、OCR、取色、二维码、图片历史 | 现有截图与贴图插件 |
| 软件卸载、残留检查 | 使用 Geek 等外部应用，通过普通应用入口启动；启动插件提供 Windows 的“已安装应用”和“程序和功能”页面 |
| 计算与命令执行 | 宿主内置；输入 `=` 进入计算，输入 `>` 进入 PowerShell 命令模式，详见 [计算与命令输入](quick-input.md) |
| 剪贴板历史、翻译工作台、文本处理、批量重命名、笔记、待办 | 适合各自独立插件；本次未新增这些业务功能。截图内已有选区翻译能力 |
| 全盘文件搜索、窗口与进程控制、自动化 | 适合独立插件；本次未实现 |

来源：[uTools 官方插件专题](https://www.u-tools.cn/plugins/topic/96/)、[uTools 系统工具专题](https://www.u-tools.cn/plugins/topic/13/index.html)、[uTools 启动偏好](https://www.u-tools.cn/docs/guide/preferences.html)、[Microsoft Windows 设置 URI](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)、[Microsoft 设备管理器](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/using-device-manager)。功能归属是本项目的设计判断。

## 更新

系统入口需要 ptools 0.1.2 和应用启动插件 0.1.2。使用新版完整包，先从托盘“关闭”旧版，再运行新版；已安装的旧应用启动插件会自动升级。配置、历史和停用状态保留，已卸载的插件不会自动重新安装。索引后台刷新完成后即可搜索。
