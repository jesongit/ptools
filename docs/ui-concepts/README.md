# NOVA Tools 界面风格原型

8 个独立设计方案，共用「截图与贴图」工具场景，用于选择 ptools 的下一版视觉方向。

## 预览

直接用浏览器打开本目录的 `index.html`，无需安装依赖。入口支持切换方案、双方案对比和收藏；点击「完整打开」按浏览器窗口原尺寸体验。

也可以在本目录执行 `node preview.cjs`，再访问 http://127.0.0.1:4173 。服务仅监听本机，仅读取本目录中的 HTML。

| 编号 | 风格 | 文件 |
| --- | --- | --- |
| 01 | 清透蓝白学园 | 01-academy.html |
| 02 | 黑灰橙战术终端 | 02-tactical.html |
| 03 | 奶油粉紫治愈 | 03-healing.html |
| 04 | 都市潮流漫画 | 04-manga.html |
| 05 | 现代和风二次元 | 05-wa.html |
| 06 | 星夜魔法工坊 | 06-magic.html |
| 07 | 复古像素桌面 | 07-pixel.html |
| 08 | 极简专业工作站 | 08-minimal.html |

每个方案由独立子智能体设计，HTML 内嵌样式、交互脚本与原创 SVG 图形，无网络资源依赖。统一包含左侧导航、截图工作区、最近任务、右侧参数和底部状态栏。

所有截图、任务和设备信息均为演示数据，按钮只模拟运行，不访问本机截图、剪贴板、插件或设置。收藏保存在当前浏览器的本地存储中。

这些网页是视觉与交互原型，没有改变现有 Rust / Win32 软件实现。
