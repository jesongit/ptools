# 计算与命令输入

ptools 0.1.5 在同一个输入框中提供应用搜索、实时计算和 PowerShell 命令。按 `Alt+Space` 唤起窗口，普通文字搜索应用。在应用搜索模式输入 `=` 进入计算，输入 `>` 进入命令模式；左侧图标显示当前模式，触发符号自动从输入框移除，之后只输入算式或命令正文。

触发符号仅在应用搜索模式识别。进入工具后，输入框保持当前模式；命令中的 `>` 或 `=`（如重定向、赋值或字符串）按普通 PowerShell 正文处理，不会退出工具或切换到计算。

## 实时计算

先输入 `=` 进入计算模式，再输入 `2 + 3 * 4`，下方立即显示 `14`。编辑算式时结果同步更新；在输入框按 `Enter` 复制结果。输入框只显示算式正文，计算不启动外部程序。

| 计算模式中的正文 | 结果 |
| --- | --- |
| `2 + 3 * 4` | `14` |
| `(12 + 8) / 5` | `4` |
| `1e3 + 2.5` | `1002.5` |
| `10 % 3` | `1` |
| `2 ^ 10` | `1024` |
| `-2 ^ 2` | `-4` |

支持小数、科学计数法（如 `1e-3`）、括号、正负号和 `+ - * / % ^`。`%` 是取余，`^` 是幂；幂运算优先于正负号，并从右向左结合，如 `2 ^ 3 ^ 2` 等于 `2 ^ (3 ^ 2)`。常量支持 `pi`、`π` 和 `e`，字母常量不区分大小写；相邻数值或常量之间需要明确写运算符，例如 `2 * pi`。

结果使用浮点计算，一般显示 15 位有效数字。括号不匹配、除零、缺少运算符、无效实数或数值超出范围时显示错误；“复制结果”禁用，输入框 `Enter` 和全文复制快捷键不会复制错误提示。首版提供算术和常量，没有函数、变量或单位换算。

## PowerShell 命令

先输入 `>` 进入命令模式，再输入 `Get-Date`，在输入框按 `Enter` 执行。命令的文本输出和错误信息显示在下方结果框，状态行显示退出码和耗时。输入命令时只展示待执行提示；输入不会自动运行命令。完成后再次在输入框按 `Enter` 可重新执行当前命令。

命令模式中的正文示例：

```powershell
Get-Date
Get-Location
Get-ChildItem | Select-Object -First 10 Name, Length
ipconfig
Write-Output '第一行'; Write-Output '第二行'
Write-Output 'a > b = c'
```

命令按当前 Windows 用户权限执行。每次启动新的 Windows PowerShell，使用 `-NoProfile -NonInteractive`，不加载个人 PowerShell 配置。初始工作目录默认为用户目录，执行前显示在状态行；目录不可用时回退到程序的当前工作目录或系统临时目录。变量和 `cd` 只影响本次命令，需要多个步骤时可在同一条命令中使用分号或管道。

命令运行期间再次按 `Enter` 不会启动另一个进程。可继续编辑输入，上一条命令的结果不会覆盖新内容；上一条执行完成后才能运行下一条命令。

每次执行最多运行 30 秒、捕获 1 MiB 输出。超时或输出超过上限时停止当前命令及其子进程，面板显示相应状态，保留已捕获正文。“复制结果”和 `Ctrl+Shift+C` 只复制这部分正文，不包含退出码、耗时、超时或截断提示。没有输出时复制按钮不可用；命令失败但有输出时仍可复制已捕获的输出。

首版没有持续会话、交互式终端、命令历史或跨次执行的变量与目录状态。需要输入密码、确认或持续交互的程序应在普通终端中运行。

## 结果面板和快捷键

计算和命令共用输入框下方的结果面板：标题与状态信息在上方，右侧为“复制结果”，下方为只读、可选择文字的多行正文。计算结果使用大字号；命令输出使用 Consolas 等宽字体并支持滚动。

| 操作 | 行为 |
| --- | --- |
| 输入框 `Enter` | 计算模式复制结果；命令模式执行或重新执行 |
| 点击“复制结果” | 复制当前结果正文 |
| `Ctrl+Shift+C` | 在计算或命令模式复制完整结果正文 |
| 结果框 `Ctrl+C` | 复制原生文字选区 |
| 结果框或复制按钮 `Enter` | 复制当前结果正文 |
| `Tab` / `Shift+Tab` | 在输入框、结果框和可用的复制按钮之间向前 / 向后切换 |
| 工具模式 `Esc` | 返回进入前的应用搜索并恢复原查询 |
| 应用搜索模式 `Esc` | 隐藏窗口 |
| 正文已为空时 `Backspace` / `Delete` | 退出工具并恢复之前的搜索查询 |
| `Ctrl+A` 后 `Backspace` / `Delete` | 清空正文并保留工具模式；空输入上再次删除才退出 |
| 右上角 `···` | 打开内置菜单 |

应用搜索模式仍可用 `Tab` 打开菜单。工具模式通过左侧图标识别，输入框没有可删除的模式前缀。清空正文会留在当前工具；正文已经为空时再按 `Backspace` 或 `Delete` 返回之前的搜索，或直接按 `Esc` 返回。返回搜索后再次按 `Esc` 才隐藏窗口。

## 验证脚本

界面和剪贴板回归使用 PowerShell 7 的 STA 模式：

```powershell
pwsh -STA -File ./scripts/verify-quick-input.ps1 -VerifyClipboard
```

脚本使用隔离的数据目录；剪贴板检查会保存并恢复原来的剪贴板内容。结果与界面截图存放在 `artifacts/quick-input-*`。
