# 原生截图与卸载插件

这两个插件使用独立的 Rust / Win32 程序。宿主注册快捷键与搜索入口，建立索引时不启动工具。再次唤起时复用仍在使用的窗口；最后一个工具窗口关闭后退出。宿主停用插件或退出时会回收它的进程树。Win 拖动手势由宿主内的小型消息线程和鼠标钩子监听；手势期间临时监听 Win / Esc。没有截图后台服务或搜索索引服务。停用或卸载截图插件会释放手势线程和钩子。

## 安装

完整分发包首次启动时安装三个随包插件。已有数据目录也会首次补入新的截图与卸载插件，后续手动卸载会保持卸载状态。只想添加某一个功能时，在“插件管理”选择安装，选取 `capture-0.1.0.ptplugin` 或 `uninstaller-0.1.0.ptplugin`。旧版宿主不支持交互插件，需要同时更新 `ptools.exe`。

已安装旧截图插件时，更新宿主后还需在插件管理中卸载旧截图插件，再安装新版 `capture-0.1.0.ptplugin`；卸载保留历史和个人设置。只替换宿主或随包文件不会覆盖已安装插件。新版清单声明 `quick` 动作后宿主才启用 Win 拖动手势。

## 截图和贴图

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 截图 | Ctrl+1 |
| 快速截图并在原选区贴图 | 按住左 / 右 Win + 鼠标左键拖动，先松开左键完成，再松开 Win |
| 贴出剪贴板 | Ctrl+2 |
| 图片历史 | Ctrl+3 |
| 延时与固定区域、保存区域预设 | Alt+1 |
| 矩形框选 / 界面元素 | 拖动 / 移动后单击；关闭元素检测则选择窗口 |
| 全部屏幕 | Ctrl+A 或“全屏” |
| 精确坐标与宽高 | “尺寸”或右键“精确尺寸” |
| 临时正方形选区 | 按住 Shift 拖动 |
| 移动 / 改变选区大小 | 框选工具下拖动选区内部 / 拖动边缘与八个控制点；方向键 / Ctrl+方向键 |
| 复制 / 贴图 / 另存为 | Enter 或 Ctrl+C / Ctrl+T / Ctrl+S |
| 离线 OCR / 翻译 | Shift+C / Ctrl+Q |
| 二维码 / 取色 | Q / C；取色格式在设置中选择 |
| 撤销 / 重做 | 工具栏弯箭头，或 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z |
| 贴图标注 / 移动 | 空格，或右键选择工具 / 拖动 |
| 缩放 / 透明度 | 滚轮 / Ctrl+滚轮 |
| 关闭贴图 / 取消截图 | Esc 或双击贴图 |

Win 拖动显示透明框选边框；松开左键后自动复制、贴图，并在共用历史中保存一张截图。Esc 或提前松开 Win 取消；不足 4×4 像素的区域不截图。开始手势时只按 Win，避免占用 Win + Ctrl / Alt / Shift 等组合。边框在截图前移除，原程序不会收到该手势的左键按下 / 松开。普通鼠标移动和点击继续传递；释放 Win 不弹出开始菜单，也不阻止正常的 Win 键释放。搜索“快速截图并贴图”也可进入松开鼠标即贴图的框选模式。

标注包含矩形、椭圆、直线、折线、箭头、画笔、荧光笔、文字、序号和马赛克。折线逐点单击，Enter、Esc 或双击结束绘制。截图输出可加圆角、阴影、边框和鼠标指针；固定比例在设置中填写，例如 `16:9`。

框选后显示图标工具栏，悬停时下方显示工具名称、快捷键与操作提示，当前工具高亮，无可撤销或重做的内容时对应按钮变灰。下方色板和三个粗细按钮设置下一条标注，已有标注保留各自样式；粗细同时影响文字大小和马赛克块大小。常用工具快捷键为 V 框选/移动、R 矩形、E 椭圆、L 直线、F 折线、A 箭头、P 画笔、H 荧光笔、T 文字、N 序号、M 马赛克。识别文字、翻译、二维码、长截图、精确尺寸、全屏和设置放在“…”菜单中。文字输入取消或为空不会创建标注；绘制过程中双击不会误复制或关闭窗口。

截图选区外变暗，选区显示像素尺寸与八个控制点；选区完成后收起取色放大镜，绘制期间隐藏工具栏。移动已有选区会同步移动标注，调整边缘不会清空标注。工具栏优先放在选区下方，空间不足时移到上方或屏幕内，并按 DPI 和可用宽度调整布局。

贴图默认显示一圈深色细边框与内侧浅色描边，边框独立于图片内容，复制、保存与历史图片不会带入这圈窗口边框。空格进入标注后，独立浮动工具栏显示在贴图外侧，跟随移动与缩放，小贴图也不会被工具遮挡；再次按空格收起工具栏并恢复拖动贴图。关闭贴图会同时释放浮动工具栏。

取色附像素放大，支持 HEX、RGB、HSL、HSV。二维码结果弹窗展示，确定后复制；识别到单个网址时可选择打开。贴图支持图片、剪贴板文字、文件名称与路径、HEX / RGB / HSL / HSV 色块，以及现有 GIF / WebP 动图；文件贴图可右键打开原文件。

长截图只做基础纵向拼接：框选后点“长截图”，滚动原窗口，再点完成复制、贴图或保存。要求相邻画面有稳定重叠；动态页面、固定悬浮元素或过快滚动可能无法拼接。预览尽量放在选区外，选区太大时采样会临时隐藏预览。

截图与贴图共用图片历史，默认保留最近 7 天，可改为 1–3650 天。完整 PNG 和缩略图存到插件数据目录，重启仍在；重启不自动恢复贴图。历史双击或 Enter 贴出，Ctrl+C 复制。过期内容在下次使用历史时清理。区域预设是手动保存的设置，不记录自动选区历史。

OCR 只在操作时启动短期进程，完成后释放引擎。优先使用本机中文 Windows OCR 组件，其次英文；适合中英文与数字，识别后可在贴图上拖选文字并复制。没有语言组件时在 Windows 语言设置中安装“文字识别”。本机未打包为 MSIX 也已通过识别验证，但[微软文档](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr?view=winrt-26100)对桌面程序支持声明有包身份要求，因此不同系统仍需验证；组件不可用会提示，不会转成云端 OCR。没有公式或表格结构识别。

翻译在设置中配置 `chat`（兼容聊天 API）或 `deepl`，填写完整 HTTPS 地址、密钥及需要的模型名。默认中译英、其他文字译为简体中文，结果弹窗展示。图片不发送给翻译服务，只有识别出的文字会发送。密钥保存在当前 Windows 用户的凭据管理器中，配置文件不写密钥；移动数据目录或换电脑需重新填写。没有配置服务时 OCR 仍可独立使用。

没有录制、公式渲染、贴图锁定 / 穿透或文件搜索。

## 软件卸载

只读取桌面应用的卸载登记，不列商店应用。支持名称、版本、发布者、登记大小、安装日期、安装位置，搜索和表头排序；缺少的字段保持空白，不为计算大小扫描整个安装目录。

“卸载已选”运行软件自带卸载程序，勾选多个则依次运行。成功结束后扫描该软件可定位的安装目录、同名用户数据、卸载登记、同名注册表和快捷方式。部分安装器会另开进程，无法确认完成时需自行完成后手动扫描。

“强制删除”直接进入残留预览，不运行原卸载程序。所有残留默认不勾选，列出路径与匹配依据，同名匹配标为需确认；只删除明确勾选并确认的项。不会删除共享安装目录、系统目录、注册表父级或通过目录连接跳出的路径。清理遇到权限不足才请求 Windows 管理员权限。没有清理记录、还原备份或全盘模糊扫描。

## 数据与快捷键

插件数据在宿主数据目录的 `plugin-data/capture` 和 `plugin-data/uninstaller`。停用或卸载插件会移除快捷键与搜索入口；图片缓存和个人设置保留，重新安装可继续使用。

宿主 `settings.json` 的 `plugin_hotkeys` 可覆盖动作快捷键，例如 `{"capture:capture":"Ctrl+Shift+S","capture:custom":""}`；空字符串取消该快捷键。修改文件前退出宿主，重启生效。支持 Ctrl、Alt、Shift、Win，加字母、数字或 Space；冲突会在宿主提示。

实际构建、界面与资源验证结果见 `artifacts` 中的独立测试输出。翻译的网络服务和真实软件卸载不属于自动验收；卸载清理测试仅操作专门创建的临时样例。
