# 原生截图与贴图插件

截图与贴图插件使用独立的 Rust / Win32 程序。宿主注册快捷键与搜索入口，建立索引时不启动工具。再次唤起时复用仍在使用的窗口；最后一个工具窗口关闭后退出。宿主停用插件或退出时会回收它的进程树。Win 拖动手势由宿主内的小型消息线程和鼠标钩子监听；手势期间临时监听 Win / Esc。没有截图后台服务或搜索索引服务。停用或卸载截图插件会释放手势线程和钩子。

## 安装

完整分发包首次启动时安装应用启动和截图与贴图两个插件。已有数据目录会自动升级版本较旧的随包插件，保留配置、历史、使用记录和停用状态；后续手动卸载会保持卸载状态。只想添加截图功能时，在“插件管理”选择安装，选取 `capture-0.1.5.ptplugin`。旧版宿主不支持全部交互功能，需要同时更新 `ptools.exe`。

使用 ptools 0.1.3 完整包升级时，先从托盘“关闭”旧版，再启动新版。原先随包的自研软件卸载插件会被移除，旧插件数据保留。软件卸载可使用 Geek 等现有应用；应用启动插件提供 Windows 的“已安装应用”和“程序和功能”入口。

## 截图和贴图

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 截图 | Ctrl+1 |
| 快速截图并在原选区贴图 | 按住左 / 右 Win + 鼠标左键拖动，先松开左键完成，再松开 Win |
| 贴出剪贴板 | Ctrl+2 |
| 图片历史 | Ctrl+3 |
| 延时与固定区域、保存区域预设 | Alt+1 |
| 矩形框选 / 界面元素 | 拖动 / 移动后单击；关闭元素检测则选择窗口 |
| 全部屏幕 | Ctrl+A 或“全屏” |
| 精确坐标与宽高 | “尺寸”或右键“精确尺寸” |
| 临时正方形选区 | 按住 Shift 拖动 |
| 移动 / 改变选区大小 | 框选工具下拖动选区空白处 / 拖动边缘与八个控制点；方向键 / Ctrl+方向键 |
| 复制 / 贴图 / 另存为 | Enter 或 Ctrl+C / Ctrl+T / Ctrl+S |
| 选择图中文字 / 翻译 | 默认开启文字框选，文字上直接拖选，松开即复制；Shift+C 开关，Ctrl+C / Enter 再次复制；贴图 Ctrl+A 全选文字，截图已有文字选区时 Ctrl+A 全选文字；Ctrl+Q 翻译 |
| 文字标注 | T 后单击图片，在图内直接输入；Enter 完成，Shift+Enter 换行，Esc 取消；点击图片或切换工具提交 |
| 二维码 / 取色 | Q / C；取色模式下单击图片复制颜色，取色格式在设置中选择 |
| 撤销 / 重做 | 工具栏弯箭头，或 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z |
| 贴图标注 / 移动 | 空格，或右键选择工具 / 拖动 |
| 缩放 / 透明度 | 滚轮 / Ctrl+滚轮 |
| 关闭贴图 / 取消截图 | Esc 或双击贴图 |

Win 拖动显示透明框选边框；松开左键后自动复制、贴图，并在共用历史中保存一张截图。Esc 或提前松开 Win 取消；不足 4×4 像素的区域不截图。开始手势时只按 Win，避免占用 Win + Ctrl / Alt / Shift 等组合。边框在截图前移除，原程序不会收到该手势的左键按下 / 松开。普通鼠标移动和点击继续传递；释放 Win 不弹出开始菜单，也不阻止正常的 Win 键释放。搜索“快速截图并贴图”也可进入松开鼠标即贴图的框选模式。

标注包含矩形、椭圆、直线、折线、箭头、画笔、荧光笔、文字和序号。马赛克是画笔色板中的棋盘样式，选中后沿笔迹涂抹，支持单击点涂，不再框选矩形区域。折线逐点单击，Enter、Esc 或双击结束绘制。截图输出可加圆角、阴影、边框和鼠标指针；固定比例在设置中填写，例如 `16:9`。

框选后显示图标工具栏，标注工具合并为“矩形 / 椭圆”“直线 / 折线 / 箭头”“画笔 / 荧光笔”三组。各组主按钮显示该截图或贴图窗口最近选择的成员图标，点击直接使用该成员；点击右侧小三角展开带图标与文字名称的菜单，选择后更新主按钮。文字和序号各自保留按钮，马赛克仍在下方画笔色板的棋盘样式中选择。

悬停时下方显示工具名称、快捷键与操作提示，当前工具高亮，无可撤销或重做的内容时对应按钮变灰。下方色板和三个粗细按钮设置下一条标注，已有标注保留各自样式；粗细同时影响文字大小、马赛克笔迹宽度和块大小。常用工具快捷键保留为 V 框选/移动、R 矩形、E 椭圆、L 直线、F 折线、A 箭头、P 画笔、H 荧光笔、T 文字、N 序号、M 马赛克画笔，键盘选择组内工具也会更新该组主按钮。文字框选仍为独立开关，可与任何标注工具同时使用；复制图片、复制文字、翻译、二维码、取色、长截图、精确尺寸、全屏、设置与打开原文件各用独立图标外显。不可用功能变灰，窄屏时自动折行，没有“更多”按钮。文字输入取消或为空不会创建标注；绘制过程中双击不会误复制或关闭窗口。

截图选区外变暗，选区显示像素尺寸与八个控制点；选区完成后收起取色放大镜，绘制期间隐藏工具栏。移动工具下，按住没有文字的位置可拖动截图框或贴图，并清除之前的文字框选；拖动边缘优先调整截图框大小。移动已有选区会同步移动标注，调整边缘不会清空标注。工具栏优先放在选区下方，空间不足时移到上方或屏幕内，并按 DPI 和可用宽度调整布局。

贴图默认显示一圈深色细边框与内侧浅色描边，边框独立于图片内容，复制、保存与历史图片不会带入这圈窗口边框。空格进入标注后，独立浮动工具栏显示在贴图外侧，跟随移动与缩放，小贴图也不会被工具遮挡；再次按空格收起工具栏并恢复拖动贴图。关闭贴图会同时释放浮动工具栏。

取色附像素放大，支持 HEX、RGB、HSL、HSV。二维码结果弹窗展示，确定后复制；识别到单个网址时可选择打开。贴图支持图片、剪贴板文字、文件名称与路径、HEX / RGB / HSL / HSV 色块，以及现有 GIF / WebP 动图；文件贴图可右键打开原文件。

长截图只做基础纵向拼接：框选后点“长截图”，原截图框保持位置与大小不变，框内显示实时页面并允许直接滚动原窗口。复制、贴图、保存、暂停 / 继续、取消五个操作图标竖向排列，缩略图紧贴图标列；根据当前屏幕剩余空间，按右侧框外、左侧框外、右侧框内、左侧框内的顺序选择位置。面板按 DPI、屏幕空间与长图比例调整，不再弹出固定尺寸预览窗或大文字按钮。Enter / Ctrl+C 完成复制、Ctrl+T 贴图、Ctrl+S 保存、Esc 取消；自定义快捷键冲突时使用图标。要求相邻画面有稳定重叠；动态页面、固定悬浮元素或过快滚动可能无法拼接。选框始终显示，框内面板在采样时短暂隐藏，复制与保存不会带入操作图标、缩略图或选框。

截图与贴图共用图片历史，默认保留最近 7 天，可改为 1–3650 天。完整 PNG 和缩略图存到插件数据目录，重启仍在；重启不自动恢复贴图。历史双击或 Enter 贴出，Ctrl+C 复制。过期内容在下次使用历史时清理。区域预设是手动保存的设置，不记录自动选区历史。

文字框选默认开启，工具栏使用亮起的开关表示状态，可与标注工具同时保持开启。截图区域完成或贴图打开后自动在后台识别；识别期间仍可移动与标注，图片或截图区域变化后丢弃旧结果并重新识别。文字上直接拖选，松开鼠标复制所选文字并保留高亮，单击选择整词；可选择词内的部分字符，中英文间距与跨行换行保留。空白位置按当前工具执行移动或绘制，文字输入、序号和取色工具优先执行自身操作。关闭开关后，文字位置也执行当前工具的操作。识别完成不会自动复制全文或关闭窗口；存在文字选区时 Ctrl+C / Enter 复制文字，“复制图片”图标继续输出图片。

OCR 使用短期进程，完成后释放引擎。优先使用本机中文 Windows OCR 组件，其次英文；适合中英文与数字。字符位置按识别词框近似划分；GIF / WebP 在识别或保留文字选区时暂停在当前帧。没有语言组件时在 Windows 语言设置中安装“文字识别”。本机未打包为 MSIX 也已通过识别验证，但[微软文档](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr?view=winrt-26100)对桌面程序支持声明有包身份要求，因此不同系统仍需验证；组件不可用可从文字开关的悬停提示查看，关闭再开启可重试。没有公式或表格结构识别。

翻译在设置中配置 `chat`（兼容聊天 API）或 `deepl`，填写完整 HTTPS 地址、密钥及需要的模型名。默认中译英、其他文字译为简体中文，结果弹窗展示。图片不发送给翻译服务，只有识别出的文字会发送。密钥保存在当前 Windows 用户的凭据管理器中，配置文件不写密钥；移动数据目录或换电脑需重新填写。没有配置服务时 OCR 仍可独立使用。

没有录制、公式渲染、贴图锁定 / 穿透或文件搜索。

## 数据与快捷键

截图插件数据在宿主数据目录的 `plugin-data/capture`。停用或卸载插件会移除快捷键与搜索入口；图片缓存和个人设置保留，重新安装可继续使用。

宿主 `settings.json` 的 `plugin_hotkeys` 可覆盖动作快捷键，例如 `{"capture:capture":"Ctrl+Shift+S","capture:custom":""}`；空字符串取消该快捷键。修改文件前退出宿主，重启生效。支持 Ctrl、Alt、Shift、Win，加字母、数字或 Space；冲突会在宿主提示。

实际构建、界面与资源验证结果见 `artifacts` 中的独立测试输出。翻译的网络服务不属于自动验收。
