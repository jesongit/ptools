# ptools 界面规范：02 黑灰橙战术终端

状态：2026-10-01 选定，适用于所有第一方原生工具界面。
视觉参考：[02 交互原型](ui-concepts/02-tactical.html)。产品名称使用 **ptools**；NOVA Tools 仅为选型原型名称。

## 设计原则

炭黑工作面、暖白文字、橙色操作强调。优先清晰、秩序和长时间阅读，使用细分隔线、矩形模块、紧凑编号和小面积切角建立战术终端的身份。二次元气质来自统一图形语言，不依赖角色立绘。

保留原生桌面工具的效率：搜索框按需出现，截图仍直接框选屏幕，贴图仍贴在原处。原型中的三栏是设计参考，不把小型启动器或浮动工具栏强行改造成后台工作台。

## 颜色令牌

实现的唯一来源为 `crates/ui/src/lib.rs`。Win32 COLORREF 使用 BGR 存储，应通过 `rgb` 转换，不直接照抄十六进制 CSS 值。

| 令牌 | sRGB | 用途 |
| --- | --- | --- |
| BACKGROUND | `#191B1E` | 窗口、画布周围、搜索工作面 |
| SURFACE | `#23262B` | 表单、工具栏、输入框 |
| RAISED | `#2C3036` | 次级按钮和悬停面 |
| BORDER | `#454B54` | 分隔、输入边框、表格结构 |
| TEXT | `#F0EEE8` | 正文、标题、可操作图标 |
| MUTED | `#ADB3BD` | 辅助说明、时间、单位 |
| DISABLED | `#777E89` | 禁用文字，同时保留禁用语义 |
| ACCENT | `#F4A13B` | 主操作、选中标记、键盘焦点 |
| ACCENT_HOVER | `#FFB75E` | 主操作悬停 |
| SELECTION | `#3C3125` | 选中行、激活工具背景 |
| SUCCESS | `#91B49D` | 完成、连接正常 |
| DANGER | `#F18F83` | 强制删除、错误、破坏性动作 |

橙色按钮上使用 BACKGROUND 深色文字。普通正文使用 TEXT；不要使用橙色铺满页面或以灰色隐藏有效操作。状态同时使用文字、图标或勾选，不只靠颜色。截图图像、颜色样本与标注颜色属于用户内容，绝不套用界面主题。

## 排版与布局

- 中文正文使用 Microsoft YaHei UI / Microsoft YaHei，拉丁正文使用 Segoe UI 系列；数字、编号与技术值可使用 Consolas。字号以原生显示尺度校准，正文约 14–16 px，辅助约 12–13 px，标题约 20–24 px。
- 基础间距为 4，常用 8 / 12 / 16 / 24。标签和输入左对齐；主区与底部状态区域明确分开。
- 面板以 1 px 描边区分，不依赖大阴影。圆角限于微圆角；切角用于主按钮、徽记等小面积部位。
- 每个区域只强调一个主动作。工具操作和破坏性按钮分开；搜索与筛选保持在列表之前，状态说明保持在列表之后。
- 大窗口随尺寸调整列表和输入宽度；小窗口保留滚动，不遮挡确认/取消。桌面缩放下文字、图标和点击区域应同步校准。

## 控件与状态

| 控件 | 默认 | 悬停 / 焦点 / 选中 |
| --- | --- | --- |
| 主按钮 | 橙底深字 | 悬停浅橙；键盘焦点细线框；按下有轻微位移 |
| 次按钮 | 灰底暖白字，细边框 | 悬停抬亮，焦点橙色描边 |
| 危险按钮 | 深底浅红字，细边框 | 不作为默认主按钮；保留原有确认流程 |
| 输入框 | 深灰底暖白字 | 原生光标、选择、输入法和键盘行为保留 |
| 结果框 | 实底、只读、可选择的多行文字 | 原生文字选择与复制保留；命令输出可滚动 |
| 开关/复选框 | 方形细框与文字标签 | 勾选用橙色和明确勾形；空格可切换 |
| 列表 | 深底、清楚行距 | 暖棕选中底 + 橙色标识；整行仍可识别 |
| 工具栏 | 实底深灰、统一线形图标 | 激活暖棕底橙图标；完成按钮橙底深图标 |
| 状态栏 | 与主区细线分隔 | 简短中文反馈，不编造设备参数或进度 |

运行时保留现有防重复执行和禁用逻辑；不可用按钮降亮度且不能执行。支持原有 Tab、Enter、Esc、方向键、Ctrl+J/K 与截图快捷键。焦点样式不能取代可访问名称，按钮文字仍保留在原生控件中。

## 各界面应用

| 界面 | 规范应用 |
| --- | --- |
| 应用搜索、菜单、插件、设置 | 同一套背景、选中行、橙色图标与底部提示；保留应用原图标 |
| 实时计算与 PowerShell 命令 | 左侧图标显示当前模式，输入框仅保留正文；下方共用标题、状态信息、右侧复制按钮和多行结果框；计算结果大字号，命令输出用 Consolas |
| 截图选区 | 橙色选框与控制点；屏幕原始颜色不变；尺寸/取色提示使用深色底 |
| 截图与贴图工具栏 | 深色实底、橙色选中与完成操作、清晰禁用状态；色板仍为真实颜色 |
| 贴图、OCR 选词、长截图 | 深色边缘与提示条，图片/文字内容不变；选词框使用主题强调色 |
| 图片历史 | 深色缩略图列表，文字/时间层次和选中边框一致 |
| 截图插件设置、翻译设置、文字/链接输入、识别结果 | 共享表单主题，输入区实底，确认主按钮和取消次按钮 |

系统文件选择器、系统消息确认、托盘菜单和 UAC 保持 Windows 自身界面与安全语义，不伪装为自绘系统对话框。Geek 等外部应用保留自己的界面。

## 计算与命令结果面板

应用搜索中输入 `=` 或 `>` 进入对应工具模式。触发符号随后从输入框移除，左侧图标持续显示计算或命令模式；输入框仅显示算式或命令正文。前缀只在应用搜索模式识别，工具正文里的 `>`、`=` 不触发模式切换，命令中的重定向、赋值和字符串保持原义。

计算与命令保持同一条输入框和同一套结果面板结构：上方标题、状态元信息和右侧“复制结果”，下方只读、可选择的多行正文。计算突出大字号数值；命令正文使用 Consolas，长输出保留滚动和原生文字选择。标题、退出码、耗时、超时和截断状态与正文分开，复制完整结果时仅复制正文。

计算随输入实时更新，错误状态以文字和颜色共同表达，并禁用结果复制。命令输入显示待执行提示，在输入框按 `Enter` 后才运行；运行中展示状态且阻止重复执行，完成后显示退出码与耗时。命令失败、有部分输出、没有输出和达到运行限制均使用明确状态，不以一块空白表示失败，也不把提示混入可复制的输出。用户改变输入后，旧命令结果不得覆盖新内容。

计算和命令模式的 `Tab` / `Shift+Tab` 在输入、输出和可用的复制按钮之间切换；`Ctrl+Shift+C` 复制结果正文，原生 `Ctrl+C` 保留选区复制。输入框 `Enter` 复制计算结果或执行命令；结果框和复制按钮上的 `Enter` 复制结果。工具模式的 `Esc` 返回应用搜索并恢复进入前的查询，搜索模式再按 `Esc` 才隐藏窗口。工具正文已为空时 `Backspace` / `Delete` 同样返回之前的搜索；`Ctrl+A` 删除全文只清空正文并保留模式，空输入上的下一次删除才退出。菜单通过右上角 `···` 打开；应用搜索模式仍以 `Tab` 打开菜单。具体用法见 [计算与命令输入](quick-input.md)。

## 实现与验收

`ptools-ui` 提供颜色、绘制辅助和原生控件主题；desktop / tools 共享同一依赖。自绘工具栏只引用令牌，不更改渲染到导出图片的内容。控件子类必须保留默认消息处理、原有 ID 和键盘行为，销毁时解除子类；GDI 对象按调用或进程生命周期管理。

验收覆盖搜索/菜单/插件/设置、计算与命令结果面板和截图/贴图/历史/表单；运行 workspace 测试、Clippy、构建以及宿主和工具集成检查。结果面板检查模式图标、正文前缀移除、空正文删除退出、搜索查询恢复、字号层次、滚动、文字选择、复制正文、焦点顺序和执行状态。实际检查深色文字、选中/焦点、缩略图和主按钮，不以仅编译通过代替视觉验证。记录平台对话框和未实测场景的边界。
